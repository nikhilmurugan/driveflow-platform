#  DriveFlow Platform — Online Car Rental Management System

DriveFlow Platform is a real-time full-stack online car rental web application that allows users to browse available vehicles, register accounts, book rental cars, manage reservations, and interact with an administrative management system.

Designed as a production-style web platform, DriveFlow combines frontend technologies with backend services and a relational database to provide a complete end-to-end vehicle rental experience.

---

## Project Overview

DriveFlow is built as a responsive full-stack application that simulates a real-world car rental service. The system supports customer registration, secure login, vehicle management, booking workflows, rental history, and administrator operations using a connected SQL database.

---

## Features

### User Module

* User Registration & Login
* Secure Authentication
* Browse Available Cars
* Search & Filter Vehicles
* Real-Time Car Booking
* Rental History
* Profile Management

### Car Rental Module

* Vehicle Availability Status
* Booking Confirmation
* Rental Duration Selection
* Pricing Information
* Booking Management

### Admin Module

* Add / Update / Delete Cars
* Manage Customers
* View Bookings
* Update Vehicle Availability
* Rental Management Dashboard

### Database Module

* SQL-based relational database.
* Stores users, vehicles, bookings, payments, and rental records.
* Real-time CRUD operations.

## Installation & Setup

### 1. Clone Repository

```bash
git clone https://github.com/YOUR_USERNAME/driveflow-platform.git
```

### 2. Configure Backend

* Install XAMPP.
* Place the project inside the `htdocs` directory.
* Start Apache and MySQL.

### 3. Import Database

* Open phpMyAdmin.
* Create a new database.
* Import `sql/driveflow_database.sql`.

### 4. Run Application

Open:

http://localhost/driveflow-platform
